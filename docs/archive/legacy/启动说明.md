# RK3576 RKNN 程序启动说明

## 🚀 快速启动 (推荐)

### 方法1: 一键启动

```bash
cd ~/rk3576_rknn_targeting
bash quick_start.sh
```

这个脚本会自动:
1. ✅ 启动性能模式
2. ✅ 检查并编译程序(如需要)
3. ✅ 运行RKNN目标跟踪

---

### 方法2: 完整启动(带详细输出)

```bash
cd ~/rk3576_rknn_targeting
bash start_performance_mode.sh
```

这个脚本会:
1. 设置CPU/GPU/NPU性能模式
2. 检查RGA硬件
3. 自动编译(如需要)
4. 启动程序并显示配置

---

## ⚙️ 手动启动

### 步骤1: 启动性能模式

```bash
cd ~/rk3576_rknn_targeting
sudo bash tools/rk3576_performance.sh
```

### 步骤2: 编译程序(首次或修改后)

```bash
cd cpp_fast_targeting
bash build_rga.sh
```

### 步骤3: 运行程序

```bash
cd build
./rkfast_target \
  --model ../../models/best_rk3576_int8.rknn \
  --camera /dev/video73 \
  --width 640 --height 480 --fps 60 \
  --fourcc MJPG \
  --core-mask 01 \
  --no-window \
  --stats-interval 2.0
```

## 🔧 参数调整

### 修改相机设备

如果你的相机不是 `/dev/video73`,修改脚本中的:

```bash
--camera /dev/video0  # 改成你的设备号
```

查看可用相机:
```bash
ls -l /dev/video*
```

### 修改NPU核心数

```bash
--core-mask 0    # 单核
--core-mask 01   # 双核(推荐)
--core-mask 012  # 三核
--core-mask auto # 自动
```

### 修改分辨率

```bash
--width 640 --height 480   # 当前
--width 1280 --height 720  # 更高分辨率
```

### 启用调试窗口

```bash
# 去掉 --no-window,改为:
--window --display-interval 2
```

## 🐛 常见问题

### 问题1: 权限不足

```
Permission denied
```

**解决:**
```bash
sudo bash quick_start.sh
```

### 问题2: RGA初始化失败

```
RGA init failed (RGA init failed: -1), using OpenCV fallback
```

**解决:**
```bash
# 检查RGA设备
ls -l /dev/rga

# 设置权限
sudo chmod 666 /dev/rga

# 添加用户到video组
sudo usermod -aG video $USER
newgrp video
```

### 问题3: 相机打开失败

```
could not open camera: /dev/video73
```

**解决:**
```bash
# 查看可用相机
ls -l /dev/video*

# 测试相机
v4l2-ctl --list-devices

# 修改脚本中的相机设备号
```

### 问题4: 模型文件未找到

```
could not open model: models/best_rk3576_int8.rknn
```

**解决:**
```bash
# 检查模型路径
ls -l models/

# 修改脚本中的模型路径
--model /path/to/your/model.rknn
```

### 问题5: 帧率仍然很低 (pre=9ms)

```
stats frame_fps=27.5 ... pre=9.0ms
```

**说明:** RGA未生效,使用OpenCV降级

**解决:**
```bash
# 1. 检查RGA编译
ldd cpp_fast_targeting/build/rkfast_target | grep rga
# 应该看到: librga.so => /usr/lib/librga.so

# 2. 重新编译
cd cpp_fast_targeting
rm -rf build
bash build_rga.sh

# 3. 检查内核模块
dmesg | grep rga
lsmod | grep rga
```
