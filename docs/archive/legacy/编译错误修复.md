# 编译错误修复说明

## 问题描述

编译时出现以下错误:

1. **错误1**: `rga_preprocessor_` 未声明
   ```
   error: 'rga_preprocessor_' was not declared in this scope
   ```

2. **错误2**: RGA API参数不匹配
   ```
   error: too few arguments to function 'imresize_t'
   error: zero-size array '__args'
   ```

## 如果仍有问题

### RGA库版本不兼容

如果仍然报错,可能是RGA库版本问题。检查:

```bash
# 查看RGA头文件
cat /usr/include/rga/im2d_single.h | grep imresize_t

# 查看库版本
pkg-config --modversion librga
```

如果API不同,可以临时禁用RGA:

```bash
cd build
cmake .. -DRKFAST_USE_RGA=OFF
make -j$(nproc)
```

这样会使用OpenCV降级,虽然慢一些(pre=9ms),但能正常运行。
