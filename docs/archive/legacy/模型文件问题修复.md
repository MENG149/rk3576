# 模型文件问题修复

## 问题: could not open model

```
could not open model: ../../models/best_rk3576_int8.rknn
```

---

## 解决方案

### 方案1: 检查模型文件位置

在RK3576板上运行:

```bash
cd ~/rk3576_rknn_targeting

# 查找所有RKNN模型
find . -name '*.rknn'

# 查看models目录
ls -la models/
```

### 方案2: 创建models目录并放置模型

```bash
cd ~/rk3576_rknn_targeting

# 创建models目录
mkdir -p models

# 将你的RKNN模型复制到这里
cp /path/to/your/model.rknn models/best_rk3576_int8.rknn
```

### 方案3: 修改启动脚本使用正确的模型路径

如果你的模型在其他位置,编辑启动脚本:

```bash
nano quick_start.sh
```

修改这一行:
```bash
--model ../../models/best_rk3576_int8.rknn \
```

改为你的实际路径:
```bash
--model /home/user/your_actual_model.rknn \
```

### 方案4: 直接运行并指定模型路径

```bash
cd ~/rk3576_rknn_targeting/cpp_fast_targeting/build

./rkfast_target \
  --model /path/to/your/actual/model.rknn \
  --camera /dev/video73 \
  --width 640 --height 480 --fps 60 \
  --fourcc MJPG \
  --core-mask 01 \
  --no-window \
  --stats-interval 2.0
```

## 如何获取RKNN模型

如果你还没有RKNN模型,需要转换:

### 从YOLOv8/YOLOv5 PyTorch模型转换:

```python
# 在PC上运行 (需要rknn-toolkit2)
from rknn.api import RKNN

# 1. 导出ONNX
# yolo export model=best.pt format=onnx imgsz=640

# 2. 转换为RKNN
rknn = RKNN(verbose=True)

# 配置
rknn.config(
    target_platform='rk3576',
    quantized_dtype='asymmetric_quantized-8',
    optimization_level=3
)

# 加载ONNX
rknn.load_onnx(model='best.onnx')

# 构建
rknn.build(do_quantization=True, dataset='./dataset.txt')

# 导出
rknn.export_rknn('best_rk3576_int8.rknn')

print('转换完成!')
```

然后将 `best_rk3576_int8.rknn` 上传到RK3576板:

```bash
# 在PC上
scp best_rk3576_int8.rknn user@board-ip:/home/user/rk3576_rknn_targeting/models/
```

## 临时解决方案 (测试程序是否正常)

如果暂时没有模型,可以先禁用RGA测试OpenCV路径:

```bash
cd ~/rk3576_rknn_targeting/cpp_fast_targeting
rm -rf build
mkdir build && cd build
cmake .. -DRKFAST_USE_RGA=OFF
make -j$(nproc)

# 然后找到任意RKNN模型测试
./rkfast_target --model /path/to/test.rknn --camera /dev/video0 --no-window
```
