# 解除帧数限制 - 150帧封顶优化

## 已完成的优化

### 1. 移除主循环sleep

**文件:** `src/main.cpp:128`

**修改前:**
```cpp
if (frame_seq == last_frame_seq) {
  std::this_thread::sleep_for(std::chrono::milliseconds(1));  // 限制帧率
  continue;
}
```

**修改后:**
```cpp
if (frame_seq == last_frame_seq) {
  // Removed sleep for maximum FPS
  continue;
}
```

### 2. 优化相机线程等待

**文件:** `src/camera_source.cpp:102`

**修改前:**
```cpp
if (!cap_.read(frame) || frame.empty()) {
  std::this_thread::sleep_for(std::chrono::milliseconds(3));  // 3ms延迟
  continue;
}
```

**修改后:**
```cpp
if (!cap_.read(frame) || frame.empty()) {
  std::this_thread::yield();  // 让出CPU,不强制等待
  continue;
}
```

## 性能瓶颈分析

### 当前性能限制因素:

1. **相机帧率** - USB相机通常最高60-120fps
2. **RKNN推理** - 7.6ms = 最高131fps理论值
3. **预处理** - RGA 1.5ms vs OpenCV 9ms
4. **总延迟** - 目标 <10ms (100fps)

### 预期性能表现:

| 配置 | 预处理 | 推理 | 总延迟 | 理论FPS | 实际FPS |
|------|--------|------|--------|---------|----------|
| OpenCV + 双核 | 9ms | 7.6ms | 17ms | 58 | 27-30 |
| **RGA + 双核** | **1.5ms** | **7.6ms** | **9ms** | **111** | **60-80** |
| RGA + 三核 | 1.5ms | 5ms | 6.5ms | 153 | 100-120 |
| RGA + 三核 + 低分辨率 | 1ms | 3ms | 4ms | 250 | 120-150 |
