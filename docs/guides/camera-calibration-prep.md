# 相机标定 · 动手前的准备清单

- 目的：给 HF868-2 / OV2710（2.7mm、约 135° 广角、640×480 MJPG）标定出**相机内参 K + 畸变系数**，供 P0-2 去畸变、角度域映射使用。
- 这颗镜头视场很宽，画面边角畸变大，**必须实测标定**，没有现成参数文件可下载。
- 板端环境已确认：OpenCV 4.6.0，支持 ChArUco（旧版 API）与 `fisheye.calibrate`，`findChessboardCornersSB` 也在。两种标定板都可行。

---

## 一、标定板：选哪种

| 方案 | 优点 | 适合 |
|---|---|---|
| **ChArUco（推荐）** | 部分可见也能用；广角拍四角更鲁棒；抗遮挡 | 你手持板子在画面里转，覆盖边角方便 |
| 普通棋盘格 | 打印简单、无需生成特定图案 | 备选 |

**标定板图案已生成**：`docs/guides/charuco_A4_6x8_30mm.png`（A4 / 300 DPI）。
- 规格：ChArUco 6×8 格，方格 30mm，marker 22.5mm，字典 DICT_4X4_50。
- 打印时选**实际大小 / 100%**，关掉"适应页面"。图上有一条比例尺，打印后量它应为 **50.0mm**，对上就说明没被缩放。

## 二、明天要准备的东西

1. **打印标定板**
   - 能打多大打多大：A4 够用，A3 更好（广角下板子占画面越大越准）。
   - 打印时**关掉"适应页面/缩放"，用 100% / 实际大小**打印。
   - 打印后我可以给你个"打印自检"：用尺子量图案上标注的基准线，确认没被缩放。

2. **量实际方格尺寸（关键）**
   - 打印机几乎不会精确 100%，所以**打印完必须用直尺/游标卡尺量一个方格的真实边长**，精确到毫米（比如量 10 个方格总长再除以 10 更准）。
   - 这个真实尺寸要填进标定工具，填错会让整个尺度错掉。

3. **把板子贴平（关键）**
   - 标定板**必须绝对平整**，一点弯都会污染结果。
   - 用喷胶/双面胶把纸**平整贴在硬板上**：泡沫板、亚克力板、硬夹板、玻璃都行。
   - 别直接贴墙（会起皱、鼓包），别用软纸板。

4. **补光（可选但推荐）**
   - 均匀光照，避免反光/阴影/过曝。哑光纸比亮面纸好（少反光）。

## 三、拍摄要点（明天采集时照做）

采集脚本我会写好，你拿着板子按下面这些覆盖场景就行：

- **分辨率用 640×480**（和实际工作分辨率一致，标定才有效）。
- **拍 20~30 张**，把标定板摆到画面的**九宫格每个格子**都覆盖到，尤其是**四个角**（广角畸变在边角最重，四角不够会标不准）。
- **多角度、多倾斜**：正对、左右倾、上下倾各来几张（板子相对相机有 15°~45° 的倾斜很重要，纯正对无法约束畸变）。
- **多距离**：覆盖你实际打靶的工作距离范围（近的、远的都拍）。
- **板子保持平、别抖**：慢一点，避免运动模糊；每次停稳再拍。
- **整板尽量清晰**：ChArUco 允许部分出画，但主要标定图要保证图案清楚、对比高。

## 四、明天回来告诉我这几个参数

我按这些给你出标定板图案 + 配好采集/标定工具：

1. 你能打印的最大尺寸？（A4 / A3 / 其它）
2. 打印后实测的**方格真实边长**（mm）——这个拍完/打印后量，先记着。
3. 你实际打靶的**工作距离范围**（大概最近多少 cm、最远多少 cm）。

## 五、我这边会做的（你准备好后）

1. **标定板图案生成**：按你的打印尺寸生成 ChArUco（或棋盘格）PNG/PDF。
2. **采集工具** `tools/calib_capture.py`：实时预览 + 自动检测到标定板就抓拍存图，带四角覆盖提示，你只管举着板子转。
3. **标定工具** `tools/calibrate_camera.py`：吃这些图，同时跑 rational pinhole 和 fisheye 两种模型，用留出图比**重投影误差**择优，输出 `camera_profile`（K、畸变系数、分辨率、误差、日期、校验和）。
4. **接入管线**（P0-2）：`undistortPoints` 去畸变 + 角度映射，替换现在 `aim_writer` 里的 `sx/sy` 线性缩放。

## 六、常见坑（避开）

- 打印被缩放 → 尺度全错。**务必 100% 打印 + 实测方格边长**。
- 板子不平 / 拍时抖 → 畸变系数发散。**贴硬板 + 停稳再拍**。
- 只拍正对、只拍画面中间 → 畸变约束不足，边角依旧歪。**要倾斜、要覆盖四角**。
- 分辨率和实际工作不一致 → 内参不通用。**统一 640×480**。
- 标定只看训练重投影误差就宣称好 → 会过拟合。**用留出图评估**（工具会自动做）。
