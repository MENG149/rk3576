# 02 — 从 C 结构体到 C++ 类

## 你已经会的：C 结构体

```c
// C 语言：结构体是数据的容器
struct Box {
    float x1;
    float y1;
    float x2;
    float y2;
};

// 使用
struct Box b;
b.x1 = 0.0f;
b.y1 = 0.0f;

// 相关函数在外面
float box_width(struct Box b) {
    return b.x2 - b.x1;
}
```

问题：**数据和操作数据的函数是分开的**。项目大了以后，你不知道哪个函数操作哪个结构体。

---

## C++ struct：函数可以住进去

```cpp
// C++ struct：数据 + 函数在一起
struct Box {
    float x1 = 0.0f;   // ← C++ 可以在声明时给默认值
    float y1 = 0.0f;
    float x2 = 0.0f;
    float y2 = 0.0f;

    float width() const {       // ← 成员函数（方法）
        return x2 - x1;         // 直接访问结构体里的变量，不需要传参
    }
};

Box b;              // C++ 不需要写 struct 关键字
b.x1 = 10;          // 数据成员用 . 访问
float w = b.width(); // 成员函数也用 . 访问
```

这个 `width()` 叫**成员函数（method）**，它不需要 `Box` 参数——因为它"就住在 Box 里面"，直接看到所有成员变量。

---

## class 是什么：就是 struct 换了个锁

```cpp
struct Box {
    float x1;    // struct 里默认是 public（谁都能访问）
};

class Camera {
    int fd_;     // class 里默认是 private（外面不能访问）
};
```

**struct 和 class 的唯一区别**：默认访问权限不同。

习惯用法：
- struct：纯数据容器（像你的 types.hpp）
- class：有复杂行为、需要隐藏内部细节的（像 camera_source、rknn_detector）

---

## 三个访问标签：public / private / protected

```cpp
class CameraSource {
public:              // ← 下面这些谁都能调
    bool Open(std::string* error);
    void Close();
    bool ReadLatest(cv::Mat* frame, double* timestamp, uint64_t* seq) const;

private:             // ← 下面这些只有类自己能调，外面看不见
    void CaptureLoop();          // 内部线程函数
    cv::VideoCapture cap_;       // OpenCV 的相机对象
    cv::Mat latest_;             // 最新帧缓存
    //       ↑ _ 后缀是习惯，表示"这是私有成员变量"
};
```

类比：
- **public** = 餐厅菜单，客人随便点
- **private** = 厨房后厨，客人不能进

你项目的 `CameraSource` 暴露了 `Open/Close/ReadLatest` 三个接口，把采集线程、帧缓存全部藏起来——外面调用者不需要知道内部细节。

## 构造函数（Constructor）：出生时自动执行

C 语言里你手动初始化：

```c
struct Box b;
b.x1 = 0; b.y1 = 0; b.x2 = 0; b.y2 = 0;  // 每次都写一遍，烦
```

C++ 有**构造函数**，对象创建时自动调用：

```cpp
class RectTracker {
public:
    explicit RectTracker(const AppConfig& config);  // ← 构造函数声明
    //     ↑ explicit = 禁止隐式转换（好习惯，防止意外）

private:
    AppConfig config_;
    float x_ = 0.0f;      // ← 也可以在声明处给默认值
    float y_ = 0.0f;
    // ...
};

// 构造函数的实现（在 tracker.cpp 里）
RectTracker::RectTracker(const AppConfig& config) : config_(config) {}
//                                                ↑ 初始化列表：config_ = config
```

**初始化列表** `: config_(config)` 等价于 `this->config_ = config`，但是更高效。

约定：类名后面跟 `()` 就是构造函数，贴在一起看：
```
RectTracker(const AppConfig& config)
类名        参数
→ 这是一个构造函数，接收一个 AppConfig 引用
```

---

## 析构函数（Destructor）：死亡时自动清理

```cpp
class CameraSource {
public:
    explicit CameraSource(const AppConfig& config);  // 构造
    ~CameraSource();                                  // 析构：名字是 ~类名
    // ↑ 对象销毁时自动调用，用于释放资源
};
```

**你项目里的典型析构函数：**

```cpp
// camera_source.cpp
CameraSource::~CameraSource() { Close(); }
// 析构时自动关闭相机，不用手动记得关

// rknn_detector.cpp
RknnDetector::~RknnDetector() { Close(); }
// 析构时自动释放 RKNN 模型内存
```

这就是 C++ 最重要的机制：**RAII（资源获取即初始化）**——大白话就是"谁创建谁销毁，自动的"。

C 语言里你得手动 `free()`、`fclose()`，C++ 里析构函数帮你做，你可能会忘，它不会忘。

## this 指针：指自己

在成员函数里，`this` 是指向当前对象的指针：

```cpp
class RectTracker {
    float x_ = 0.0f;

    void Clamp(const cv::Size& frame) {
        x_ = ClampFloat(x_, 0.0f, frame.width);           // 直接用成员名
        this->x_ = ClampFloat(this->x_, 0.0f, frame.width); // 等价写法
        // this-> 一般省略，只有在参数和成员同名时才需要
    }
};
```

## 禁止复制/移动：= delete

你项目的关键类全都有这四行：

```cpp
class RknnDetector {
public:
    RknnDetector(const RknnDetector&) = delete;            // 禁止拷贝构造
    RknnDetector& operator=(const RknnDetector&) = delete;  // 禁止拷贝赋值
    RknnDetector(RknnDetector&&) = delete;                  // 禁止移动构造
    RknnDetector& operator=(RknnDetector&&) = delete;       // 禁止移动赋值
};
```

为什么要删掉？因为 `RknnDetector` 里面装着 NPU 硬件上下文——如果复制一份，谁负责释放？两个对象同时操作 NPU？直接禁止复制最安全。

这四行就是你告诉编译器："这个对象是**独一份的**，别随便复制。"

## 智能指针：std::unique_ptr

C 语言用 `malloc/free` 管理内存，容易忘 free。C++ 有自动管理：

```cpp
// 原始指针（C 风格）
RknnDetector* det = new RknnDetector(config);
det->Open(&error);
// ... 用完后必须 delete det;  很容易忘！

// 智能指针（C++ 风格）
auto det = std::make_unique<RknnDetector>(config);
det->Open(&error);
// ... 离开作用域时自动 delete，永远不会忘
```

**你项目 main.cpp 里的用法：**

```cpp
auto detector = std::make_unique<RknnDetector>(config);
// auto = std::unique_ptr<RknnDetector>，自动推导类型
```

`std::unique_ptr` 翻译：**独占所有权指针**——我是唯一持有者，我死了资源就释放。

## C 结构体 → C++ 类 速查表

| 概念 | C | C++ |
|------|-----|------|
| 数据+函数组合 | 分开写 | class/struct 里写一起 |
| 默认访问 | struct 全公开 | class 默认 private |
| 初始化 | 手动逐字段赋值 | 构造函数自动执行 |
| 清理 | 手动 free/close | 析构函数自动执行 |
| 禁止复制 | 没有（靠规矩约束） | `= delete` 编译期禁止 |
| 内存管理 | malloc/free | new/delete + 智能指针 |
| 成员访问 | `.` | `.`（完全相同） |

## 练习 A：Box 计算器

把这个练完再往下看。在电脑上新建一个文件 `practice_a_box.cpp`：

```cpp
#include <iostream>   // 相当于 C 的 stdio.h，但用 cout 代替 printf
#include <cmath>      // fmax, hypot 等

// ===== 第一步：定义一个 Box 结构体 =====
struct Box {
    float x1 = 0.0f;
    float y1 = 0.0f;
    float x2 = 0.0f;
    float y2 = 0.0f;

    // 成员函数：宽度
    float width() const {
        return std::fmax(1.0f, x2 - x1);
    }

    // 成员函数：面积
    float area() const {
        return width() * height();
    }

    // 成员函数：高度
    float height() const {
        return std::fmax(1.0f, y2 - y1);
    }
};

// ===== 第二步：写一个外部函数，计算两个 Box 的重叠面积 =====
float overlap_area(const Box& a, const Box& b) {
    float ox1 = std::fmax(a.x1, b.x1);
    float oy1 = std::fmax(a.y1, b.y1);
    float ox2 = std::fmin(a.x2, b.x2);
    float oy2 = std::fmin(a.y2, b.y2);
    float ow = ox2 - ox1;
    float oh = oy2 - oy1;
    if (ow <= 0.0f || oh <= 0.0f) return 0.0f;
    return ow * oh;
}

// ===== 第三步：主程序 =====
int main() {
    // C++ 可以用列表初始化（C++11 起支持）
    Box a{10.0f, 10.0f, 100.0f, 80.0f};
    Box b{60.0f, 40.0f, 150.0f, 120.0f};

    std::cout << "Box A: " << a.width() << " x " << a.height()
              << " area=" << a.area() << "\n";
    std::cout << "Box B: " << b.width() << " x " << b.height()
              << " area=" << b.area() << "\n";
    std::cout << "Overlap area: " << overlap_area(a, b) << "\n";

    // ===== 第四步：挑战 =====
    // 1. 给 Box 加一个 center_x() 和 center_y() 成员函数
    // 2. 加一个构造函数 Box(float x1, float y1, float x2, float y2)
    // 3. 写一个 IOU 函数：overlap_area(a,b) / (a.area() + b.area() - overlap)

    return 0;
}
```

编译运行：

```bash
g++ -std=c++17 -o practice_a practice_a_box.cpp
./practice_a
```

预期输出：

```
Box A: 90 x 70 area=6300
Box B: 90 x 80 area=7200
Overlap area: 1600
```

做完后把挑战部分的 3 个任务完成，你对 struct → class 就彻底熟了。
