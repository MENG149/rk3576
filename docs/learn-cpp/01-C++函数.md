# 01 — C++ 函数：C 函数上多了什么

## 你已知的 C 函数

```c
// C 语言函数：返回值类型 + 函数名 + (参数列表) + {函数体}
int add(int a, int b) {
    return a + b;
}

void say_hello(void) {
    printf("hello\n");
}
```

这就是你会的。C++ 函数完全兼容这种写法，然后额外加了 **5 个新东西**。

---

## 新东西1：引用（&）—— 比指针更安全的别名

C 语言里想"在函数里修改外面的变量"，必须传指针：

```c
// C 写法：指针
void swap(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
// 调用：swap(&x, &y);  ← 必须取地址，很烦
```

C++ 多了一种东西叫**引用**，就是个别名，不用解引用：

```cpp
// C++ 写法：引用
void swap(int& a, int& b) {   // ← & 放在类型后面，表示"引用"
    int tmp = a;   // 直接用，不用 *
    a = b;
    b = tmp;
}
// 调用：swap(x, y);  ← 不用取地址，直接传
```

记忆方法：
| 符号 | C | C++ |
|------|-----|------|
| `int* p` | 指针，用 `*p` 取值 | 同左 |
| `int& r` | 不存在 | 引用，用 `r` 直接取值 |

**你项目里到处都是引用，因为图像数据很大，复制一份太慢：**

```cpp
// types.hpp 里到处都是这样的参数：
inline float BoxWidth(const Box& box) {   // const Box& : 对 box 的只读引用
    return std::max(1.0f, box.x2 - box.x1);  // 不复制 Box，直接用原数据
}
```

如果不用引用写 `BoxWidth(Box box)`，每次调用都会把整个 Box 复制一遍——虽然 Box 很小无所谓，但 `cv::Mat`（图像，几百KB）这样搞直接卡死。

**const &** = 只读引用，是最常见的传参方式：不复制、不改原数据。

---

## 新东西2：函数重载 —— 同名不同参

C 语言不能有两个同名函数。C++ 可以，只要**参数不同**：

```cpp
// 同名函数，不同参数列表，编译器自动选
void print(int x)    { std::cout << "整数: " << x << "\n"; }
void print(float x)  { std::cout << "浮点: " << x << "\n"; }
void print(int x, int y) { std::cout << x << " " << y << "\n"; }

// 调用时编译器自动分：
print(5);       // 走第一个
print(3.14f);   // 走第二个
print(1, 2);    // 走第三个
```

**你项目里的重载例子（tracker.hpp/cpp）：**

```cpp
// RectTracker 有两个 Update 函数，根据传进来的类型自动选
void Update(const Detection& detection, ...);   // RKNN 检测结果进来 → 走这个
void Update(const RefinedRect& rect, ...);      // ROI 精修结果进来 → 走这个
```

调用方不用关心类型，编译器自动匹配。这在 C 里你得写两个不同名字的函数（`UpdateByDetection` / `UpdateByRect`）。

## 新东西3：默认参数 —— 不传就用默认值

```cpp
// 第三个参数有默认值，调用时可以不传
void draw_circle(int x, int y, int radius = 10);

draw_circle(100, 200);       // radius 默认 10
draw_circle(100, 200, 30);   // radius 传 30，覆盖默认值
```

**你项目里的例子（rect_refiner.hpp）：**

```cpp
std::optional<RefinedRect> Refine(
    const cv::Mat& frame_bgr,
    const Box& guide_box,
    const std::optional<cv::Point2f>& reference_center = std::nullopt) const;
    //                                           ↑ 默认值是"空"，调用方可以不传
```

规则：**默认参数必须从右往左排**，不能跳着给默认值。

---

## 新东西4：inline 函数 —— 编译时直接展开

C 语言也有 inline，但 C++ 里更常用。意思是**把函数体直接插入调用位置**，省去函数调用的开销：

```cpp
// types.hpp 里全都是 inline
inline float BoxWidth(const Box& box) {
    return std::max(1.0f, box.x2 - box.x1);
}
// 编译器会把 BoxWidth(b) 直接替换成 max(1.0f, b.x2 - b.x1)
// 不产生真正的函数调用
```

什么时候用：**短小的、被频繁调用的函数**。BoxWidth 在主循环每帧都跑好几次，inline 能省点时间。

---

## 新东西5：函数可以放在 struct/class 里面

C 语言的 struct 只能存数据。C++ 的 struct 里面可以写函数：

```c
// C 语言：数据归数据，函数归函数
struct Box { float x1, y1, x2, y2; };
float box_width(struct Box b) { return b.x2 - b.x1; }  // 独立函数
```

```cpp
// C++：函数可以住在 struct 里面
struct Box {
    float x1, y1, x2, y2;

    float width() const { return x2 - x1; }   // ← 成员函数(method)
    float height() const { return y2 - y1; }
};

Box b{0, 0, 10, 20};
float w = b.width();   // 用 . 调用成员函数
```

**const 放在函数后面**（`width() const`）表示"这个函数不会修改任何成员变量"。这是 C++ 特有的语法。

你项目里没用这种写法——types.hpp 选择了外部 inline 函数 `BoxWidth(const Box&)` 而不是成员函数 `box.width()`。两种风格都可以，效果差不多。

## C 函数 → C++ 函数 速查表

| 特性 | C | C++ |
|------|-----|------|
| 基本语法 | `int f(int x) {}` | 完全一样 |
| 传引用 | 不存在 | `int f(int& x)` 改原值，不用 `*` |
| 只读引用 | 不存在 | `int f(const Box& b)` 不复制、不能改 |
| 同名函数 | 不允许 | 重载：参数不同即可同名 |
| 默认参数 | 不允许 | `int f(int x, int n = 10)` |
| inline | 有但少用 | 大量使用，小函数展开 |
| 成员函数 | 不存在 | `struct S { void f(); };` |
| const 成员函数 | 不存在 | `void f() const;` 不修改成员 |

---

## 小结

你只要记住 C++ 函数比 C 多的 5 张新牌：

1. **`&`（引用）** — 不复制数据，直接操作原数据
2. **重载** — 同名不同参
3. **默认参数** — 不传就用默认值
4. **inline** — 短函数直接展开，快
5. **成员函数** — 函数住进结构体里
